About Me

컴퓨터공학과 디자인이 만나는 지점

코드를 이해하는 디자이너는 단순히 시안을 그리는 것에 멈추지 않고, 소프트웨어의 아키텍처와 사용자의 인터랙션을 하나로 엮어냅니다.

"컴퓨터공학을 공부하며 배운 논리적인 문제 해결력은 제 디자인을 더 견고하고 실용적으로 만들고, 디자인에 대한 집요한 감각은 제 코드가 사용자에게 가장 따뜻하고 아름답게 닿도록 돕습니다."
Core Synergy

제가 가진 세 가지 특별한 강점

디자이너와 엔지니어 사이의 언어적 장벽을 허물고 최상의 시너지를 이끌어냅니다.

구현 가능성 기반의 UI/UX

컴퓨터공학 지식을 바탕으로 브라우저 렌더링 파이프라인, 비동기 데이터 흐름, 반응형 제약을 고려해 디자인합니다. "개발 불가능한 화려한 그림"이 아닌, 실제 제품에 즉시 녹아드는 현실적인 디자인 솔루션을 제시합니다.

DOM & CSS Engine Hand-off Frictionless Feasibility

디자인 시스템 & 토큰 설계

Figma의 컴포넌트·변수 체계와 프론트엔드의 CSS 변수·상태 관리를 1:1로 일치시킵니다. 확장성과 재사용성을 극대화한 모듈식 시스템을 구축하여 팀 전체의 생산성을 비약적으로 향상시킵니다.

Figma Tokens Component Architecture Scalability

살아 숨 쉬는 인터랙션 구현

정적인 와이어프레임을 넘어 마이크로 인터랙션, 부드러운 트랜지션, 반응형 레이아웃을 코드로 직접 프로토타이핑하고 검증합니다. 사용자가 손끝으로 체감하는 UX 디테일을 타협하지 않습니다.
